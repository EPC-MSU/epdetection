# detection

Описание модуля `detection` и того, что в нем лежит. Автор: Маракулин Андрей. Дата: 30.07.2021.

Модуль представляет собой набор функций для распознавания компонентов на печатных платах (см. [elements.md](./elements.md)). Существует пять публичных функций, которыми следует пользоваться, импортируя модуль.

## Примеры запуска

Активация виртуального окружения:

* Открыть консоль в папке `venv/Scripts`.
* Прописать в консоли `activate`, теперь команды из консоли будут выполняться в виртуальном окружении.
* Перейти обратно в корневую папку можно командой `cd ../..`.

Пример запуска распознавания из командной строки (полный список аргументов смотрите через `--help`):

```bash
python -m detection --image tests/elm_test1/image.png --draw-elements
```

Пример запуска unit тестов

```bash
python -m unittest discover test
```

Пример запуска из кода python:

```python
import cv2
from detection import detect_elements

img = cv2.imread("my_folder/my_image.png")
result = detect_elements(img, trh_prob=0.7, trh_corr_mult=1.5)
```

## Описание модуля

* `doc` - папка с описанием модуля и элементов.

### detect.py

Распознавание происходит следующим образом:

* На элементах был заранее обучен SGD-классификатор. Он подгружается в класс `Detector` из файла `.dump`.
* Выбор dump файла зависит от вызываемой функции, поскольку для разных элементов разные классификаторы.
* По входной картинке проходятся корреляционной функцией `TM_CCOEFF_NORMED` и получают карту корреляций для выбранных элементов. (В логе выглядит как Peaks).
* Далее отбираются самые сильные пики корреляционной карты (они названы `non_overlap_hyp`).
* Эти пики уточняются, считаются вероятности расположения элемента в предполагаемом положении.
* В зависимости от предполагаемого класса, выполняются так же дополнительные действия. Например, если найден край многоногого элемента, то с помощью фурье-анализа находятся пины между несколькими углами.
* Далее отсеиваются пересекающиеся совпадения.
* Координаты с указанием класса и пинов собираются в класс `Element`.
* Сопоставляя по имени найденные элементы с файлом `sizes.csv` определяются ширина и высота корпусов.
* Возвращается лист с `Element`-ами.

#### `get_element_names_by_mode`

Возвращает список имен элементов для соответствующего режима: `BGA` или `PCB`. В EyePoint используется для формирования окна настроек.

#### `detect_elements`

Функция для нахождения элементов на PCB плате.

Аргументы:
* `img` - изображение платы, на котором надо найти элементы.
* `gc` - GuiConnector (или наследник). Служит для управления прогресс-барами и прерыванием в основной программе.
* `trh_prob` - порог классификатора. Элементы с вероятностью ниже порога отсеиваются.
* `trh_corr_mult` - коэффициент классификатора. Отвечает за порог нахождения элементов внутри непересекающихся гипотез.
* `find_one` - искать один элемент на изображении или несколько.
* `elements_offset` - смещение координат. Когда распознавание происходит в выделенной рамке, то это изображение в рамке отправляется в `detect_all`, распознавание происходит в координатной системе рамки, а после `elements_offset` используется для получения координат в системе всего изображения.
* `debug_dir` - директория для дебага.
* `det_names` - список с названиями элементов для распознавания или `None`.
* `bga_szk` - что-то связанное с размерами BGA.

Возвращает:
`elements` - список обнаруженных элементов типа `Element`.

#### `detect_label`

Функция для нахождения на изображении шахматной доски калибровочной платы. Возвращает список из одного элемента, которого `bounding box` определяет границы шахматной доски. А так же в `pins` записаны два пина: один на шахматной доске, второй на контактной площадке.

* `img` - изображение калибровочной платы, на котором надо найти шахматную доску.
* `gc` - GuiConnector (или наследник). Служит для управления прогресс-барами и прерыванием в основной программе.

Возвращает:
`labels` - список с единственным элементов типа `Element`.

#### `detect_BGA`

Функция для нахождения элементов на BGA плате. Входные аргументы идентичны параметрам функции `detect_elements`. В аргументе `det_names` должно быть "BGA".

Возвращает список обнаруженных BGA элементов.

#### `detect_BGA_params`
Вспомогательная функция для распознавания BGA. Используется для нахождения поворота платы. Поэтому вызывается по окончанию сканирования платы, еще до распознавания (и для того чтобы найти поворот, распознает компоненты).

Аргументы:
* `img` - изображение BGA платы.
* `gc` - GuiConnector (или наследник). Служит для управления прогресс-барами и прерыванием в основной программе.

Возвращает:
* `ang` - угол в градусах, на который следует повернуть плату.
* `pitch` - используется для сравнения с BGA эталонами.
* `points` - используется для сравнения с BGA эталонами.

### dumps

* `clf_bga.dump` - сохраненные внутренности класса `Detector` с обученным классификатором для BGA.
* `clf_types.dump` - сохраненные внутренности класса `Detector` с обученным классификатором для PCB типов.
* `clf_types_2.dump` - сохраненные внутренности класса `Detector`. Отличается от `clf_types.dump` смещением пинов некоторых SMD-компонентов на 3%. Подробности в задаче #99598.
* `clf_label.dump` - классификатор для шахматной доски на калибровочной плате.
* `bga.csv` - файл с описанием для BGA.
* `label.csv` - файл с описанием элемента (шахматной доски).
* `types.csv` - файл с описанием для других типов.
* `sizes.csv` - реальные размеры корпусов элементов.
* `clusters.txt` - файл с кластерами элементов, используется в обучении. Предназначение не ясно.
